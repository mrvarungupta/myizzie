# For You, In Every Lifetime ❤️

A romantic 8-page/section website made for GitHub Pages.

## Files
- `index.html` — all 8 pages and your message
- `style.css` — animations, responsive design, romantic visual effects
- `script.js` — navigation, particles, touch/keyboard controls and optional music
- `music/romantic.mp3` — put your own audio file here
- `images/` — optional folder for future photos

## Publish on GitHub
1. Create a new GitHub repository.
2. Upload everything inside this folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main`, folder `/ (root)`.
5. Save and open your GitHub Pages URL.

Use the bottom Next buttons, arrow keys, spacebar, or swipe left/right on mobile.
